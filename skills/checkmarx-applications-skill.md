# Checkmarx Applications Skill

This skill provides agents with the ability to list, create, retrieve, update, and delete applications.

## Operations

- listApplications
- createApplication
- getApplication
- updateApplication
- deleteApplication

Each operation corresponds to an `operationId` in the OpenAPI spec `openapi/checkmarx-applications-api-openapi.yml`.
